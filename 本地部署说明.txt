========================================
  足球AI数据分析系统 · 本地部署使用说明
========================================

【运行环境】
已内置 Python 便携运行时（runtime 目录），无需单独安装 Python，
不联网也能打开页面（更新赛事数据时需要联网）。

----------------------------------------
一、启动网站（每次使用）
----------------------------------------
  双击  [启动网站.bat]
  → 会自动打开浏览器访问 http://localhost:8899
  → 如 8899 被占用，会自动顺延到 8900 等端口（窗口内会显示地址）
  → 关闭那个黑色命令行窗口，即停止服务

----------------------------------------
二、更新赛事数据
----------------------------------------
  方式1（手动）：双击 [更新数据.bat]，等待提示“数据更新完成”，
                然后刷新浏览器页面即可看到最新赛事。
  方式2（自动）：双击 [注册定时任务.bat] 一次，
                系统会在每天 08:00、12:00、16:00、20:00 自动抓取。
                · 注册时会弹出“用户账户控制(UAC)”，请点“是”
                · 仅在你登录 Windows 期间运行
                · 运行日志见 logs\fetch.log
  取消自动更新：双击 [卸载定时任务.bat]（同样在 UAC 弹窗点“是”）

----------------------------------------
三、目录说明
----------------------------------------
  index.html        网站主页面
  data\             赛事数据（由更新脚本自动写入）
  scripts\          数据抓取与预测引擎
  runtime\          内置 Python 便携运行时（请勿删除）
  scripts-local\    本地启动/定时任务辅助脚本
  logs\             定时抓取日志
  .github\workflows\GitHub Actions 云定时任务（本地使用不影响）

----------------------------------------
四、常见问题
----------------------------------------
  · 双击 bat 闪退：右键“以管理员身份运行”，或确认 runtime 目录完整。
  · 页面显示“暂无赛事”：双击 [更新数据.bat] 抓最新在售赛事即可。
  · 想换台电脑：把整个文件夹拷过去（含 runtime），直接双击启动即可。
  · 网址 http://localhost:8899 只在本机可访问，不会对外暴露。
